## 📑 Programma del Corso
*I macro argomenti documentati all'interno di questo repository comprendono:*
- [x] Fondamenti di C++
- [x] Variabili, Tipi di Dato e Strutture di Controllo
- [x] Funzioni e Passaggio dei Parametri
- [x] Array, Vettori e Matrici
- [x] Puntatori e Gestione Dinamica della Memoria
- [x] Classi e Programmazione Orientata agli Oggetti (OOP)
- [x] Ereditarietà e Polimorfismo

## 📂 Struttura del Repository

* `latex/` o `lezioni/`: Contiene tutti i file sorgente essenziali per la compilazione in LaTeX (`.tex`).
* `esercitazioni/`: Implementazione pratica e archivi di esercizi svolti in C++.
* `codice/` e `sandbox/`: Esempi di codice e progetti prova.
