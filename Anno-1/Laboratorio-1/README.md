## 📑 Programma del Corso
*I macro argomenti documentati all'interno di questo repository comprendono:*
- [x] Fondamenti di JavaScript
- [x] Flusso di Controllo e Problemi Algoritmici
- [x] Oggetti, Array e Stringhe (incluso gestione JSON)
- [x] Funzioni, Scope e Funzioni di Ordine Superiore
- [x] Insiemi e Dizionari

## 📂 Struttura del Repository

La navigazione è progettata per avere sia i file sorgente testabili, sia il materiale pronto per lo studio:

* `Bibbia latex/`: Contiene tutti i file sorgente per la compilazione in LaTeX (`.tex`) del documento finale, inclusa la cheat sheet e i vari capitoli.
* `Esercizi JS/`: Implementazione pratica e script in JavaScript per testare gli algoritmi visti a lezione.
* `Eserciziario_Esame/`: Raccolta di simulazioni ed esercizi per la preparazione dell'esame pratico e teorico.
* `Slide Lab /`: Slide e presentazioni fornite durante le ore di laboratorio.
* Il file **PDF Compilato**: Si trova sempre all'interno della cartella `Bibbia latex/` (es. `intro_YYYY-MM-DD.pdf`) ed è il documento master "La Bibbia di Laboratorio JS" pronto per la lettura.

---

## 📖 Come consultare gli appunti
Non è necessario avere strumenti speciali per leggere le tesine o gli appunti finali: puoi scaricare l'ultima versione del PDF compilato sfogliando la repository e cliccando sul file PDF autogenerato presente nella cartella **`Bibbia latex/`**.
